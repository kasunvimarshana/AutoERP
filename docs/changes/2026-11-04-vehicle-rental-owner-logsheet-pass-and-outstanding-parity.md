# Vehicle Rental: Owner Log Sheet Parity, Pass/Toll Outlay Integration & Customer Outstanding Drilldown

## Context & Motivation
Following a comprehensive end-to-end deep audit of the legacy visual reports and attachments (`pmglled.frx`, `pmdeblogsheet2.frx`, `pmcre1logsheet2.frx`, `pmdebinv5.frx`, `pmcrelicence.frx`), key operational parity and UX ergonomic improvements were identified and resolved:
1. **Owner Running Chart Sheet (`pmcre1logsheet2.frx`):** Vehicle owners/lessors require a monthly 31-day running chart matrix sheet detailing each day's usage with an explicit `Lessee` column, lessor identification (`Lessor ID`), and owner signature authorization.
2. **Highway Toll / Pass Outlays:** Daily toll tickets and expressway passes recorded on running charts flow through as `Pass` disbursements and are summarized into `Total Pass`.
3. **Ergonomic Driver Continuity:** Dispatchers logging 30 consecutive daily charts for single-driver contracts experienced high repetitive friction re-selecting the chauffeur on each draft; pre-populating from the most recent active driver resolves this cleanly.
4. **Customer Outstanding Age Analysis Drilldown (`pmdebinv5.frx`):** Rental invoices displayed in aging analysis now surface the underlying rental agreement reference and line description.

## Changes Made

### 1. Vehicle Rental Module Backend
- `app/Modules/VehicleRental/Http/Requests/RunningChartReportRequest.php`:
  - Added `'sheet_mode' => ['nullable', 'string', 'in:lessee,owner']`.
- `app/Modules/VehicleRental/Http/Controllers/RunningChartReportController.php`:
  - Passed `sheet_mode` parameter to report generator in both `show()` and `export()`.
- `app/Modules/VehicleRental/Services/RunningChartReportService.php`:
  - Added dual-mode running chart matrix generation (`lessee` vs `owner`).
  - Added lookup support for both `CustomerAgreement` and `OwnerAgreement`.
  - Added aggregation of `RentalExpense` with `expense_type = RentalExpenseType::Toll` to compute daily `pass` outlays and summary `total_pass`.
  - Populated row-level `'lessee'` column with the active customer/client name for each day.
- `resources/views/reports/vehicle-rental/running-chart-sheet.blade.php`:
  - Added Blade layout support for `is_owner_sheet`: `Lessor ID`, `Name of Owner`, `Lessee` table column, adjusted table footer colspans, and `Owner / Authorized Signature`.

### 2. Frontend Vehicle Rental Module
- `resources/js/modules/vehicle-rental/runningChartApi.ts`:
  - Extended `RunningChartReportParams`, `RunningChartReportData['header']`, and `RunningChartReportRow` with `sheet_mode`, `is_owner_sheet`, `lessor_id`, `owner_name`, and `lessee`.
- `resources/js/modules/vehicle-rental/RentalRunningChartReportPage.tsx`:
  - Added Sheet Type selector dropdown (`Lessee Sheet` vs `Owner Sheet`).
  - Added `Pass` column and dynamic `Lessee` column to report matrix table.
  - Added Toll / Pass Total summary card and owner signature block in owner mode.
- `resources/js/modules/vehicle-rental/RunningChartEditor.tsx`:
  - Accepted `initialDriver` prop to pre-populate driver source, employee driver, and external driver fields on new draft creation.
- `resources/js/modules/vehicle-rental/RunningChartsPanel.tsx`:
  - Derived `initialDriver` from the latest recorded chart.
  - Added direct quick links for "Print Sheet" and "Print Owner Sheet".
